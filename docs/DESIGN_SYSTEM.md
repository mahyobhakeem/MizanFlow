# نظام التصميم وتجربة المستخدم — MizanFlow (Global Enterprise Cloud Design System & RTL UX)

**المشروع:** MizanFlow (منظومة ميزان فلو السحابية لإدارة المشتريات والمخازن والتجارة)  
**الفلسفة التصميمية:** واجهة سحابية مؤسسية فائقة النقاء وعالية الكثافة (Ultra-Clean Enterprise Cloud UX) مستوحاة من معايير **Google Cloud Console** و **Google Workspace** وكبرى منصات المشتريات والمخازن وسلاسل الإمداد العالمية (مثل Flexport و Katana). تعطي الأولوية المطلقة لسرعة القراءة، وضوح البيانات المحاسبية والمخزنية، ومنع إجهاد العين.  
**التوجيه البصري:** التخلص التام من الألوان الاستعراضية، البطاقات الهلامية، وتدرجات الذكاء الاصطناعي الفاقعة (Anti-AI Clichés)، واستبدالها بالنقاء الهندسي الصريح، الحدود المجهرية الدقيقة (Hairline Borders)، والكبسولات التفاعلية الناعمة.  
**المهارة البرمجية:** [`premium-business-ui`](../.agents/skills/premium-business-ui/SKILL.md)  
**التقنيات المعتمدة:** Laravel 13.x Blade Components, Bootstrap 5.3.x RTL, Google Cloud / Enterprise Vanilla CSS Token Architecture, `@fontsource/readex-pro`, `@fontsource/plus-jakarta-sans`, `bootstrap-icons` (محزمة محلياً بالكامل عبر Vite 8 — استقلالية تامة بنسبة 100% عن شبكات CDN الخارجية).

---

## 1. فلسفة الواجهة ومبادئ التصميم (Design Philosophy)

1. **كثافة المعلومات المنظمة (Precision High-Density):** شاشات المشتريات والمستودعات والمبيعات صُممت لتمكين المسؤول والمحاسب من قراءة كافة الأرصدة، تكلفة WAC، وحالات التوريد بنظرة واحدة دون الحاجة لتمرير مستمر.
2. **الاستقلالية التامة والأمان (Zero External CDN Dependency):** كافة الأصول الرقمية (خطوط Readex Pro و Plus Jakarta Sans، ومكتبات الأيقونات والتنسيقات) مدمجة محلياً داخل حزمة Vite لضمان العمل بأعلى معايير الأمان المصرفي والشبكات المعزولة.
3. **الدقة البصرية للـ RTL:** تدفق طبيعي ومحاذاة عربية كاملة من اليمين إلى اليسار، مع الحفاظ على الأرقام المالية وأكواد الباركود وSKU والنسب باتجاه LTR متساوي العرض (`tabular-nums`).
4. **النقاء البصري والهدوء التشغيلي (Google Clean Ergonomics):** أرضية بيضاء/رمادية سحابية ناصعة ومريحة مع حدود دقيقة (`1px solid #e0e3e7`) تقسم الأقسام دون إثقال بصري.
5. **السرعة ودعم مسدس الباركود ولوحة المفاتيح:** استجابة فورية وحقول مهيأة للتنقل عبر `Tab` و `Enter` ومسح الباركود السريع.

## 3. الخطوط والطباعة والأرقام (Typography & Numerals)

* **الخط العربي المعتمد:** خط **`Readex Pro`** الرسمي محزم محلياً عبر حزمة `@fontsource/readex-pro` (بأوزان 400 Regular, 500 Medium, 600 Semi-Bold, 700 Bold). خط هندسي مفتوح مصمم للشاشات عالية الدقة.
* **الخط اللاتيني والأرقام المالية:** خط **`Plus Jakarta Sans`** عبر حزمة `@fontsource/plus-jakarta-sans` مع دعم خاصية الأرقام المتساوية العرض `font-variant-numeric: tabular-nums` عبر فئة `.num-cell`.
* **محاذاة البيانات المالية:**
  * النصوص وأسماء الأصناف والعملاء: محاذاة لليمين.
  * الأسعار والكميات وأكواد الباركود ورموز SKU: محاذاة لليسار بتنسيق LTR لضمان المقارنة العمودية السريعة.

## 4. مكونات واجهة المستخدم القياسية (Reusable Blade Components)

### 4.1 رأس الصفحة ومسار التصفح (`<x-page-header>`)
* يدعم مسار التصفح الهرمي السحابي (Breadcrumbs) المتناسق.
* يجمع العنوان الرئيسي التنفيذي، الوصف التشغيلي، وأزرار الإجراءات السريعة.

### 4.2 بطاقة المؤشرات التشغيلية (`<x-stat-card>`)
* بطاقة أداء مسطحة ونظيفة مطابقة لمؤشرات Google Analytics و Cloud Console.
* مزودة بحاوية أيقونة كبسولية ناعمة (`.stat-icon-wrapper`) ملونة حسب الحالة، وقيم رقمية كبيرة متساوية العرض.

### 4.3 شارة الحالة الذكية (`<x-status-badge>`)
* كبسولة ناعمة مزودة بنقطة دلالية (`::before`) تعكس حالات المخزون والفوترة:
  * `completed` / `approved`: خلفية خضراء ناعمة `#e6f4ea` مع نقطة `#137333`.
  * `in_transit` / `pending` / `low`: خلفية عنبرية `#fef7e0` مع نقطة `#b06000`.
  * `voided` / `danger`: خلفية حمراء `#fce8e6` مع نقطة `#c5221f`.
  * `draft` / `inactive`: خلفية محايدة `#f1f3f4` مع نقطة `#5f6368`.

### 4.4 جدول البيانات عالي الكثافة (`.table-dense` & `.table-dense-container`)
* حاوية جداول بيضاء ناصعة بإطار دقيق.
* رؤوس أعمدة مثبتة (`Sticky Header`) بخلفية رمادية خافتة `#f8fafd` مع تباين واضح.
* خلايا الأرقام مدعومة بفئة `.num-cell` لضبط اتجاه الأرقام ومنع انقلاب الفواصل في RTL.

### 4.5 وسوم الأكواد والرموز (`.code-tag`)
* تصميم كبسولي مضغوط بخلفية زرقاء فاتحة `#f0f4f9` وحد `#d3e3fd` وخط أحادي العرض مخصص لأرقام الفواتير وأكواد الأصناف والباركود.

### 4.6 حالة الفراغ الإرشادية (`<x-table-empty>`)
* رسالة توجيهية بأيقونة دائرية ناعمة وزر إجراء كبسولي مباشر.

### 4.7 شريط السلامة المخزنية الميكروي (`.stock-health-track` & `.stock-health-fill`)
* شريط تقدم دقيق بارتفاع `4px` يُعرض أسفل أرقام الأرصدة الفعلية في جداول المخازن ليعطي المسؤول قراءة بصرية فورية:
  * `health-safe`: أخضر سحابي عندما يتجاوز الرصيد حد الطلب بأمان.
  * `health-warning`: كهرماني تحذيري عند اقتراب الرصيد أو ملامسته لحد الطلب.
  * `health-danger`: أحمر صريح عند نفاد الرصيد تماماً (0).

### 4.8 كبسولات الفلاتر النشطة السحابية (`.active-filters-bar` & `.filter-chip`)
* شريط كبسولات تفاعلية بنمط Google Chips يظهر تلقائياً أعلى الجداول المفلترة، يتيح إلغاء كل فلتر منفرداً بنقرة واحدة سريعة دون إعادة تعيين النموذج بالكامل.

### 4.9 لوحة الأوامر السريعة السحابية (`Ctrl + K` Command Palette)
* نافذة عائمة سريعة الاستجابة تفتح باختصار `Ctrl + K` أو `Cmd + K` أو بالنقر على شريط البحث العلوي، تتيح للمستخدم التنقل الفوري بين كافة شاشات وأوامر المنظومة عبر لوحة المفاتيح والبحث المباشر.

### 4.10 أدوات التصدير والطباعة الرسمية (Enterprise Export & Print)
* تصدير فوري لجداول البيانات إلى ملفات Excel/CSV مع دعم كامل للترميز العربي الموحد `UTF-8 BOM` لمنع تشوه الحروف عند الفتح المباشر في Microsoft Excel.
* ترويسة طباعة رسمية (`d-none d-print-block`) تُظهر بيانات المؤسسة والتاريخ والاعتماد تلقائياً عند الطباعة.

## 5. شريط الأوامر العلوي والقائمة الجانبية (Header & Sidebar Architecture)

1. **شريط الأوامر العلوي (Global Command Bar):**
   - بارتفاع `var(--mz-header-height)` (حوالي `60px`) وخلفية بيضاء ناصعة مع حد مجهري دقيق (`--mz-border`).
   - سياق المستودع النشط التفاعلي (`.warehouse-context-pill`) يعرض اسم الفرع الفعلي للمستخدم ويرتبط مباشرة بصفحة أرصدة المستودع.
   - حقل بحث سحابي عالمي في المنتصف بنمط كبسولة Google مع اختصار `Ctrl + K` وزر بحث سريع مخصص للهواتف والأجهزة اللوحية.
   - أزرار وصول تشغيلي مباشر: اختصار نقطة البيع (POS) وقائمة منسدلة للعمليات السريعة (`+ عملية جديدة`) للفوترة والتوريد والمنتجات والعملاء من أي شاشة.
   - تنبيهات واضحة وهادئة تظهر فقط عند وجود إشعارات فعلية، وإلغاء المؤشرات الحركية والنبضات الزخرفية لتوفير بيئة عمل مريحة وخالية من التشتيت.
   - قائمة مستخدم سحابية تضم الاسم الصريح، ومعلومات الدور، وروابط فورية للوحة المؤشرات والتنبيهات وسجلات الرقابة وزر تسجيل الخروج.
2. **شريط التنقل الجانبي (Workspace Navigation):**
   - خلفية بيضاء نقية تتناغم مع مساحة العمل.
   - الروابط النشطة مميزة بكبسولة ناعمة مريحة للعين (`background: #c2e7ff`, `color: #001d35`) تتبع أسلوب Google Workspace المعياري.
   - طي تلقائي ذكي (Accordion) وعزل كامل للروابط حسب صلاحيات المستخدم (RBAC).

## 6. ضوابط وتنسيقات الطباعة (Print Standards)

* إخفاء كامل لشريط التنقل، القائمة الجانبية، أزرار التصفية، والتذييل عبر `.no-print` وقواعد `@media print`.
* إزالة الظلال والخلفيات الرمادية واستبدالها بخطوط حدودية سوداء رفيعة (`1px solid #cbd5e1`) لتوفير الحبر وضمان دقة الطباعة على الطابعات الحرارية وطابعات الليزر A4.
* توافق تام مع متطلبات الفاتورة الضريبية المبسطة وقواعد هيئة الزكاة والضريبة والجمارك (ZATCA).
